Shared engine boundary

The semantic command accepts absolute values or cumulative signed relative steps, freezes original recipient ratios and validates the complete selection before publishing. The legacy raw single-vertex setter retains its stricter behavior. No persistent format bump is required; native v22 stays.

Missing entries are added only for positive edits to a bone already bound to the mesh. A per-mesh precedence extension inserts the new influence without rearranging old entries; first appearance resolves unconstrained ties. Contradictory/repeated context blocks positive missing creation. Stored or pending Deform layout changes fail atomically. Brushes, locks, Auto, Smooth, Update bindings and multi-bone edits are outside this slice.
